# Proyecto de Unity (aún vacío)

Aquí vivirá el proyecto de Unity: escenas, 3D, interfaz y sonido. **Todavía no se crea**, porque la fase 1 es el núcleo en texto y no necesita gráficos.

## Cuándo y cómo se crea

En la fase 2, Isaias crea el proyecto desde Unity Hub, eligiendo esta carpeta (`unity/`) y la plantilla **3D (URP)**. La versión exacta de Unity (una LTS) se fija ese día y se anota aquí.

## Regla de oro

Unity **solo dibuja** lo que el núcleo decide. Ninguna regla de la vida (sueldos, semillas, eventos) se programa aquí: todo eso vive en `core/`. Unity usará el núcleo como una biblioteca compilada.
